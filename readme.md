# SnapGrid - Visual Media Search

SnapGrid is a responsive web application designed for discovering high-resolution imagery across various categories with a clean, fast interface.

### Design Decisions
1. **Category Suggestion Chips**: Added quick-select category buttons above the main content area so users can instantly trigger searches for popular topics with a single click.
2. **Slate Dark Aesthetic**: Implemented a modern slate-and-teal color scheme (`#0d1117`) to provide maximum visual contrast for image cards while distinguishing the brand identity from purple-themed reference apps.
